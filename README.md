The Coffee Financials Project attempts to analyze the business performance of a coffee shop business by integrating order frequency, item details, and 
recipe data using SQL to reveal the top 10-performing products by size and quantity. The Python NumPy, Pandas, and Matplotlib libraries
have been used to create bar graph and scatter plot visuals illustrating mean profit per category and derive a positive correlation between profit and cost. 

The purpose of this project was to explore data integration and visualization using SQL and Python- this project dives deep into revenue-cost analysis to 
determine best-selling products and what kinds of products to launch.
